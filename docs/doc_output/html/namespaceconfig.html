◆ load_config()

load_config ( )

Ładuje konfigurację aplikacji z pliku JSON.

Jeśli plik konfiguracyjny nie istnieje, tworzy go z domyślnymi wartościami.

Zwraca
Słownik (dict) zawierający ustawienia administratora i serwera SMTP.
