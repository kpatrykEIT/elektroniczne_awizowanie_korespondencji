Opis szczegółowy

Punkty końcowe (endpoints) Flask obsługujące przesyłanie plików ze zdjęciami (PC oraz ESP).

Dokumentacja funkcji

◆ esp_message()

esp_message ( )

Odbiera proste wiadomości tekstowe/statusowe w formacie JSON z modułu ESP.

@route POST /esp @request_json Dane wysłane przez ESP.

Zwraca
Odpowiedź JSON potwierdzająca odebranie wiadomości.

◆ esp_upload()

esp_upload ( )

Obsługuje zaawansowane przesyłanie zdjęć i metadanych bezpośrednio z urządzenia ESP.

Generuje unikalną nazwę pliku na podstawie znacznika czasu i powiadamia mailowo użytkownika. @route POST /esp-upload @request_form file Plik graficzny z kamery ESP. @request_form json Ciąg tekstowy JSON zawierający: device_id, user_id, message.

Zwraca
Odpowiedź JSON ze statusem 200, 400, 404 lub 500 (błąd serwera).

◆ upload_photo_from_laptop()

upload_photo_from_laptop ( )

Obsługuje przesyłanie zdjęcia paczki bezpośrednio z komputera (laptopa).

Zapisuje plik i wysyła powiadomienie e-mail do adresata. @route POST /upload @request_form file Plik graficzny (.jpg). @request_form user_id Identyfikator użytkownika docelowego.

Zwraca
Odpowiedź JSON ze statusem 200 (sukces) lub 400/404 (błąd).
